# HealthPlus-US-Member-Segmentation-And-Retention-Analysis
Conducted end-to-end member churn analysis on 500K health insurance policyholders using Python, applying RFM segmentation, hypothesis testing, XGBoost classification (AUC: 0.663), CLV regression (R²: 0.729), and time series forecasting to identify $732M in at-risk lifetime value and deliver targeted retention strategies.
